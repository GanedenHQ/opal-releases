# Opal

Assistante vocale française, gratuite, conçue par Ganeden.

La transcription et la voix tournent sur l'ordinateur ; seul le texte part vers le modèle de langue choisi (distant, ou local).

## Télécharger

**[Dernière version pour Mac (Apple Silicon)](https://github.com/GanedenHQ/opal-releases/releases/latest)**

- macOS sur puce Apple (M1 et suivantes).
- Appli signée par Ganeden et validée par Apple.
- Mise à jour automatique.

Ouvrir le DMG, glisser Opal dans Applications.
